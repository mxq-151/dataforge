# 产品能力总览

> [文档首页](README.md) › 产品与理念

按 **开发链路**、**数据治理**、**平台运维** 三类组织。每一类都能单独用，也能串成一条链路——这是 DataForge 作为企业级数据开发 AGENT 的能力底座。

**3 大能力类 · 9 个功能模块 · 需求到上线全链路**

## 01 开发链路

从业务需求描述，到可调度的线上任务。

| 模块 | 说明 | 关键能力 |
| --- | --- | --- |
| **开发助手** | 需求文档自动解析，生成可编译代码并提交调度。 | 需求生成 · 代码生成 · 编译调试 |
| **数据探查** | 库表浏览器与 SQL 编辑器一体，开发中随时验证。 | 即席查询 · 表结构 · 数据预览 |
| **作业调度** | 可视化编排工作流，实例管控与失败自动重试。 | 编排 · 监控 · 重试 |

## 02 数据治理

从口径定义，到血缘可追溯。

| 模块 | 说明 | 关键能力 |
| --- | --- | --- |
| **指标管理** | 统一指标定义与口径，检索即用，变更影响可预判。 | 口径统一 · 检索 · 影响分析 |
| **数据血缘** | 表级与字段级全链路血缘，问题定位可追溯。 | 表级 · 字段级 · 影响面 |
| **知识库** | 开发规范、技术框架与业务知识沉淀，生成前自动检索。 | 开发规范 · 技术框架 · 业务知识 |

## 03 平台运维

从权限管控，到资源保障。

| 模块 | 说明 | 关键能力 |
| --- | --- | --- |
| **系统管理** | 角色权限、用户管理、租户隔离与操作审计，问题追溯有据可查。 | 角色权限 · 租户隔离 · 操作审计 |
| **运维管理** | 存储与计算资源管控、开发规范扫描与数据价值分析。 | 资源管控 · 规范扫描 · 价值分析 |
| **问题排查** | 调度失败自动归因，日志、堆栈与上下游血缘联动定位根因。 | 日志检索 · 根因定位 · 失败重跑 |
