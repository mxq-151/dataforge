# 指标管理

> [文档首页](../README.md) › 使用教程

数仓设计文档中必须包含**"数据指标"章节**，章节标题为 `## 数据指标`（二级标题），下方用 Markdown 表格列出所有指标。指标的新增/更新都是在markdown文件中右击菜单操作完成，删除指标需要在指标管理模块完成

## 指标表格列定义

表格必须包含且仅包含以下 7 列，列名严格按此顺序，不得改名、不得增删：

| 列名 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| **指标编码** | 必填 | 全局唯一 ID，命名方式：{项目编码}_序号 | `trade_0001` |
| **指标名称** | 必填 | 业务可读的指标名称 | 日活用户数 |
| **主题域** | 必填 | 指标所属业务主题 | 用户域、交易域、流量域 |
| **指标含义** | 必填 | 指标的业务含义 | 统计当日活跃的去重用户数 |
| **计算表达式** | 必填 | 指标的 SQL 计算逻辑 | `count(distinct user_id)` |
| **过滤条件** | 可填 | 统计时需要应用的过滤条件，无则留空 | `status=1 且 channel in ('app','web')` |
| **字段来源** | 必填 | 字段所属库名表名，格式：库名.表名:字段名 | `dw.user:dws_user_id;ods.log:event_id` |

## 指标编码命名规则

指标编码为全局唯一标识，命名格式为 `{项目编码}_{序号}`：

- **项目编码** — 项目编码的小写缩写，如交易域项目使用 `trade`
- **序号** — 四位数字编号，从 0001 起递增，如 `0001`、`0002`

示例：`trade_0001`、`trade_0002`、`user_0001`

## 字段来源格式

字段来源用于明确指标的数据出处，格式为 `库名.表名:字段名`，多个来源用分号分隔，同表多字段用逗号分隔：

```
库名.表名:字段名1,字段名2;库名.表名:字段名3

# 示例
dw.trade:order_id,order_amount;ods.log:event_id
```

> [!NOTE]
> **注意**：每个指标占一行，不得合并单元格、不得使用多行文本。若同一主题域有多个指标，分多行书写。
