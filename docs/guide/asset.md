# 资产管理

> [文档首页](../README.md) › 使用教程

资产管理回答四个问题：数据**存在哪**（存储与文件资产）、数据**长什么样**（数据源与元数据）、数据**留多久**（生命周期）、数据**有没有人用**（使用统计）。

## 一、存储与文件资产

平台有两条独立的文件通道：**开发助手内的工作区文件管理**（工程代码文件），以及独立的**分布式文件浏览器**（面向数据资产的存储浏览）。**文件权限**控制的是后一条通道——即集群存储上的数据文件（详见「权限管理」）。分布式文件浏览器支持以下存储类型：

| 存储类型 | 典型用途 |
| --- | --- |
| **HDFS** | 大数据平台主存储，承载 ODS 贴源数据与中间结果 |
| **JuiceFS** | 分布式文件系统，用于需要 POSIX 语义的数据集 |
| **S3 / 对象存储** | 归档数据、外部交换数据的落地位置 |
| **本地** | 本地挂载目录，用于小数据集与临时文件的查看 |

**存储配置**由存储类型、接入地址（endpoint）、bucket、根路径、本地挂载路径等字段构成，保存后先用「连接测试」验证连通性，再进入浏览。

在文件浏览器中可执行的操作：**浏览目录、新建目录、重命名、上传、下载、预览**（文本类文件可直接预览）。

## 二、数据源与测试库

「数据源管理」中维护可供开发与探查使用的数据库连接，字段包含：数据源类型、连接方式、连接串（URL）、库名、连接状态与最近测试时间。

- **连接测试** — 新建或修改连接串后可一键测试，测试结果写入连接状态与最近测试时间；
- **元数据同步** — 对数据源执行元数据同步，把库表结构采集到平台的元数据资产中；
- **库表浏览** — 在「数据探索」中以 数据源 → 库 → 表 的树形结构浏览，支持按**表名或表注释**关键字过滤；
- **表详情** — 查看字段结构（字段名、类型、是否分区、是否主键、可空、默认值、注释），并可直接编辑字段的业务描述。

> [!NOTE]
> 环境预置了数据源 `test_datasource`，指向 PG 演示业务库 `test_db`（含 `ad_events` 示例表），可直接用于资产管理的全流程体验。

## 三、元数据资产

元数据不是在集群里定时全量扫描，而是**随 DDL 增量沉淀**：代码执行产生建表 / 改表动作时，平台增量同步该表元数据；执行 `DROP` 时直接删除本地元数据。这意味着**平台纳管的范围等于「在本平台跑过的 DDL」**，既有历史表需另行纳入。

已沉淀的元数据字段（节选）：

| 实体 | 已沉淀字段 |
| --- | --- |
| **表元数据** | 数据源 / 存储引擎 / catalog / 库 / 表 / 表类型 / 表注释 / 建表与最后修改时间 / 分区列 / 存储格式 / 压缩 / location / 行数 / 大小 / **冷热保留天数** |
| **字段元数据** | 字段名 / 类型 / 注释 / 是否分区 / 是否主键 / 序号 / 可空 / 默认值 |
| **指标资产** | 主题域 / 指标编码 / 名称 / 业务定义 / 计算表达式 / 默认过滤 / 业务与技术责任人 / 刷新周期 / 可见性，并字段级绑定到 数据源 · 库 · 表 · 字段 |

元数据描述不完整时，平台提供**未标注缺口清单**：直接输出缺注释与业务描述的表 / 字段，便于集中补齐——描述越完整，智能体生成代码的准确率越高。

## 四、数据生命周期

生命周期以**三个天数字段**表达，随表元数据一起采集，在表详情中展示：

| 字段 | 含义 |
| --- | --- |
| `hotDays` | 热数据保留天数：被高频访问、建议保留在高性能存储的时长 |
| `coldDays` | 冷数据保留天数：低频访问、可下沉到低成本存储的时长 |
| `keepDays` | 总保留天数：超过后进入归档或清理流程 |

这三个值由数据架构师在数仓设计的「生命周期」中**逐表声明**，再随 DDL 落地并在元数据中沉淀；同时可结合存储位置（location）、存储格式与压缩方式评估存储成本。

## 五、数据使用统计

资产目录提供**治理视角**的浏览与检索：可按**表 / 字段 / 指标**搜索，定位到具体资产后查看详情与治理项。

- **访问埋点** — 平台对浏览、读取、收藏、查询等行为上报访问记录，作为使用热度的数据来源；
- **使用记录** — 呈现浏览与读取趋势、字段热度明细、读取 TOP 人员（按 T+1 汇总）；
- **字段热度** — 字段级热度以 0~5 星展示，用于判断哪些字段真正被使用；
- **治理项** — 例如「未标注字段」（缺注释与业务描述）、「长期未更新表」（最后修改时间超过生命周期阈值）。

> [!WARNING]
> 使用热度依赖服务端埋点汇总，数据按 **T+1** 更新；资产目录中的部分页签（如使用记录、权限）需服务端相应接口就绪后展示完整明细。
