# 2026-10-11

## 资产管理 · 资产目录：左右两栏顶部工具带等高（修分界线错开）

**问题**（用户截图）：资产目录页签里，左栏「搜索行 + 引擎视角/规范视角」下方的分隔线，
比右栏「资产详情」头部下方的分隔线低，两条线没连成一条。

**定位**（不用猜，用真实浏览器量）：playwright + 本机 chromium，`file://` 加载一个只含
「`.ac-panel` 真实结构 + 真实 `AssetCatalogPanel.css` + 复刻的 `:root`」的静态页，
`getBoundingClientRect()` 量两侧 `border-bottom` 的 y。
- 改前：左线 y=130，右线 y=111.5 → **错开 18.5px**（900/1080/1280/1440 四个宽度一致）。
- 也顺手查清两处容易踩的点：本项目**没有全局 `box-sizing` reset**；
  `button`/`input` 不继承 `:root` 的 font-family 与 line-height（走 UA 的 Arial + normal），
  所以左栏行高在换字体栈时**不漂移**（实测 5 种字体栈均为 search 34 / views 38 / btn 29）。

**取舍**：两个方向都能对齐 —— ① 收紧左栏 18.5px；② 把右栏头部撑到 92px。
选了 ①：② 会让右栏头部出现 ~31px 死区、且白占内容区高度；① 顺带把左栏控件尺寸
拉回与全站控件一致（搜索框 30 ≈ 普通 `.ac-input` 29；视角按钮 27 = 模块条环境切换按钮 27）。

**改法**（`src/views/asset-catalog/AssetCatalogPanel.css`，4 个选择器）：
- `.ac-side__search`：`margin: 12px 12px 8px` → `10px 12px 5px`，`padding: 5px 8px` → `3px 8px`（高 34 → 30）
- `.ac-side__views`：`padding: 0 12px 8px` → `0 12px`（下沿紧贴分隔线）
- `.ac-viewbtn`：`padding: 5px 8px` → `4px 8px`（高 29 → 27）
- `.ac-main__title`：新增 `line-height: 22px`（避免继承 1.5 得到 22.5，产生半像素差）

结果：73 = 左（10+30+5 + 27+1）= 右（16+22+4+18+12+1），四个宽度下错位 **0.00px**。

**验证**：资产目录模块 4 个测试文件 29 例全过。测量脚本留在 `/tmp/ac-measure/`（`measure.js` 等）。
