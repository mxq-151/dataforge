### 后端（dataforge-server）

- **`AssetEnvParser` 迁到 `com.bigdata.common.utils.DeployEnvParser`**（旧类删除）：资产模块与 metadata
  模块都要用，放 asset 包里会让 metadata 反向依赖 asset。新增 `matches(name, env)`（env 空=不过滤；
  显式过滤时「解析不出环境」的名称被排除）与 `normalize(env)`（脏值视为不过滤，避免把结果集清空）。
- 加 env 的接口：`/asset/catalog/tree`、`/search`（**只对表/字段生效，指标无环境维度**）、`/suggest`、
  `/bookmark`、`/inventory/overview|health|top-assets|size-growth`、`/inventory/top-compute|task-delay`、
  `/metadata/annotation-gaps`。
- 环境来源两套后缀、同一约定：**表类 = 库名后缀**；**任务类 = 工作流名后缀**（提交调度把环境拼在名字末尾）。
- 过滤一律放在**权限过滤之后**：环境只缩小「看哪一套」，不改权限边界。
- `/inventory/env-project` **刻意不收窄**：前端要全环境合计作分母算「该环境占全库空间比例」。
- 标注缺口的环境条件下推到 SQL：`database_name LIKE '%!_prod' ESCAPE '!'`。
  - 理由：与 `LIMIT` 截断同层，改成内存过滤会让命中数凭空变少。
  - 必须转义 `_`（LIKE 里 `_` = 任意单字符，`%_prod` 会误配 `xaprod`）；转义字符用 `!` 而非反斜杠，
    避开 MySQL / PG 字符串字面量的反斜杠差异。已抽成 `MetadataAnnotationGapService.applyEnvFilter` 并单测锁定。
- `/bookmark` 指定环境时改走**内存分页**：环境过滤发生在解析之后，先按库分页再过滤会让页码/total 错位。
- **`LambdaQueryWrapper.select(...)` 会在构造期解析 lambda 列名**（依赖实体元数据缓存，只在 Spring 启动时建），
  纯单测里会抛 `can not find lambda cache`。只取两列的投影改用 `QueryWrapper.select("table_name","database_name")` 字符串列名。
- 新增测试：`DeployEnvParserTest`（14）、`AssetCatalogEnvFilterTest`（5，树/检索/建议过滤）、
  `MetadataAnnotationGapEnvSqlTest`（3）；契约测试加 `envBinding` / `envOmittedIsNull`。

## 追加（同日，第四轮）：资产概况的榜单表头没有吸附

用户反馈「资产概况中的表格表头没有固定」。**没读 CSS 猜，用真实 Chromium 量了**：

- 环境：playwright 1.58.2（`/Users/mxq/node_modules`）+ 已缓存的 chromium，`NODE_PATH=… node x.js`，
  `file://` 加载测试页并按 `getBoundingClientRect()` 量偏移。
- 病根：`.ac-table` 为做圆角带了 `overflow: hidden` + `border-radius`；
  `position: sticky` 只认**最近的滚动容器**，表格自身成了容器 → 表头被锚死在表格内部，
  跟着内容滚走。实测滚 120px 后 thead 相对容器顶部 **-119px**。
- 对照组（这是关键，避免改错地方）：
  | 改动 | 滚动 120px 后偏移 |
  |---|---|
  | 现状 | -119px（未吸附） |
  | **只加 `overflow: visible` + `border-radius: 0`** | **0px（吸附）✅** |
  | 只改 `border-collapse: separate` | -119px（**与此无关**） |
  | 两者都改 | 0px |
- 落地：`.ac-ov-scroll .ac-table { overflow: visible; border-radius: 0; }`（只在滚动容器内生效，
  不影响其它位置 `.ac-table` 的圆角），并把实测数字写进注释防止后人「顺手改 border-collapse」。
- 校验：引用**项目真实 CSS** 的复现页，`table.overflow=visible`、滚 120px 后偏移 **0**、
  表头背景不透明（`rgb(45,45,45)`，行不会透出来）。
- 同类排查：全仓 13 处 `position: sticky`，`.exec-tabs__table` 那两处**表格没有** `overflow: hidden`，是干净的；
  其余多为弹窗/工具条 sticky，不属同一坑。
- `tsc` 干净，asset-catalog 26 例全过（CSS 改动不影响用例，作冒烟）。
