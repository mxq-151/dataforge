## 四、改动点与风险

1. **PacedMarkdown 分块增量渲染**（`src/components/ai/parts/PacedMarkdown.tsx`）：
   将打字机文本拆成「稳定前缀（useMemo 缓存）+ 活动尾部（最后一段）」，
   只在跨越空行（段落）边界时重新解析稳定前缀，其余步进仅重解析活动尾部，
   消除长回复下 Markdown 的 O(n²) 重复解析。拆分点避开围栏代码块，且当活动尾部
   超过 1500 字符时自动退化为换行边界以限制重解析成本；
   流式结束后仍由 TextPartDisplay 用完整 GFM 一次性渲染，最终形态不变。
2. **MessageTimeline 查找索引化**（`src/components/ai/timeline/MessageTimeline.tsx`）：
   将 `renderRow` / `getMsgPart` / `assistantCopyPartID` 中的 O(n) `messages.find`
   统一替换为 O(1) 的 `entryByID` Map 索引。
3. **未改动**：`useOpencodeEvents` 的 33ms delta 合并刷新节奏、Monaco 编辑器链路、
   时间线投影核心逻辑（`projection.ts` / `rows.ts`）均保持不变。
